## 4. Architecture / Behavior Decisions

| Decision | Rationale |
|----------|-----------|
| Business-create → "Your Business is Now Active" email | Admin-created businesses must notify the contact (user requirement) |
| Brand-create → welcome email only | Avoid double-emailing; brand activation already covered by welcome-credit email |
| Notification wrapped in try/catch | Email failure must never block business/brand creation |
| SMTP app password stored without spaces | Gmail app passwords are 16 chars; spaces are display-only |
| `email_logs` table = source of truth for delivery | Every send attempt (success/fail) is logged; 0 rows = no send attempted |
