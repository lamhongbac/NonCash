## 4. Architecture Decisions Made

| Decision | Rationale |
|----------|-----------|
| BCrypt for API key hashing | Random 32-byte hex keys, only first 8 chars stored as prefix for log/UI identification |
| Outbox pattern for webhooks | VoucherEvent written to DB in same transaction as business op; WebhookDeliveryService delivers async |
| HMAC-SHA256 webhook signatures | Industry standard for webhook payload verification |
| Exponential backoff retry | 1m → 5m → 25m → 2h → 10h, max 5 retries — balances reliability vs resource usage |
| Image storage toggle (MSA/Local) | Dev fallback when MSA is unreachable; config-driven switch |
| Entity = table name, UniqueCode = `{PK}_{fieldName}` | Physical mapping to DB records; enables MSA wildcard delete per field |
| Delete-before-upload in service layer | MsaImageStorageService handles cleanup internally; controller doesn't need to know |
| RelativeUrl only in DB | Domain composed at runtime: `{CDNEndpointURL}/{RelativeUrl}` |
